# Voice2Policy 디자인 부탁 자료

이 파일과 `Voice2Policy_PPT_구현방향_백지안.pptx`를 함께 전달합니다. PPT의 앞 2장은 제작 가이드이고, 본편은 17장입니다. 본편 오른쪽 회색 영역에는 각 장의 역할, 발표자가 남길 문장, 권장 시각화, 피해야 할 표현을 적었습니다. 최종본에서는 이 영역을 삭제하고 본문 영역을 16:9 화면 전체로 넓혀 주세요.

발표가 남겨야 할 문장은 하나입니다.

> 정책서민금융은 집행률로 관리되지만, 실제 성과는 필요한 사람에게 닿는가에서 갈립니다.

분석 A~E를 같은 무게로 나열하지 않습니다. 측정 공백을 제기하고, 재원·자격·가구·공간 분석으로 근거를 쌓은 뒤, 기존 상담에서 미매칭 신호를 수집해 재정 성과관리와 배분에 돌려주는 흐름으로 구성합니다. 15분 발표를 가정했으며, 실제 제한 시간이 다르면 증거 구간의 장수를 우선 조정합니다.

## 디자인에서 지켜야 할 기준

- 한 장에는 결론을 하나만 둡니다. 슬라이드 제목이 그 결론을 말해야 합니다.
- 관측값은 파랑, 측정 공백은 빨강, 개선안은 초록, 불확실성과 조건은 회색으로 구분합니다.
- 보고서 원 그래프는 근거 확인용입니다. 최종본에서는 같은 수치로 편집 가능한 차트를 다시 그립니다.
- `연간 공급 강도`는 자격 가구 100가구당 연간 신규 공급 건수입니다. `수급률`이나 `도달률`로 바꾸지 않습니다.
- ITS의 월 1.7만 건 점프는 기술적 연관입니다. 인과 효과로 표현하지 않습니다.
- CGI는 우선 검토 순위를 위한 지표입니다. FDR 보정 후 유의한 국지 군집은 0곳이므로 특정 지역을 확정적 사각지대로 표시하지 않습니다.
- 오배분율 6.9%→4.3%는 시뮬레이션 가정에 따른 예시입니다. 월 1만 건에서 미매칭률 정밀도 ±3.6%p가 가정과 무관한 결과입니다.
- 포용이는 새 공식 앱 제안이 아닙니다. `서민금융 잇다`와 통합지원센터에 미매칭 사유 기록을 얹는 연구용 시연입니다.
